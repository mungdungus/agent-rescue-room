## Demo scenario (from Codex spec)
A customer's research agent was supposed to:
1. Gather company intelligence from web sources
2. Verify claims against retrieved context
3. Ask for human approval before drafting outbound email

What went wrong:
- Used stale retrieved context (retriever returned outdated data)
- Skipped the human approval step (conditional edge bug)
- Produced overconfident outbound message with unsupported claims
- Tool error was swallowed, agent continued with corrupted state
</context>
