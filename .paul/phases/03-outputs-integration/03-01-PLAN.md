## Goal
Replace the two remaining stub nodes (evals, debrief) with LLM-powered implementations, add a human approval gate between tribunal and evals using LangGraph's interrupt_before, and enable LangSmith tracing.

## Purpose
Completes the working pipeline. The human-in-loop gate is the interview's marquee feature: it demonstrates governance in agentic systems, which is what a Deployed Engineer at LangChain handles daily.

- LLM-powered debrief writer producing incident memos from actual diagnosis
- Human approval gate that pauses the graph and requires explicit resume
- LangSmith tracing active for all LLM calls
- End-to-end run produces real LLM output through all 6 nodes

    - Add interrupt_before=["evals"] to the compile() call

    - Replace the simple app.stream() loop with the interrupt-aware pattern:
    - First stream: runs ingest -> classify -> ground -> tribunal, then pauses
    - After pause: print the diagnosis summary for human review
    - Wait for input: prompt user to type "approve" or "reject"

    - If rejected: print message and exit
    - Second stream: continues through evals -> debrief
    - Must use a thread_id in config for checkpointing (required for interrupt)
    - Add MemorySaver as the checkpointer: from langgraph.checkpoint.memory import MemorySaver
    - Pass checkpointer=MemorySaver() to compile()
    
    The CLI output should clearly show the pause point with a visual separator and the diagnosis.
  </action>
